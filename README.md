# Универсальный конвертер

Десктопное приложение на Python для конвертации **изображений, аудио и видео** между десятками форматов. Интерфейс выполнен в стиле **Material You** на базе Flet (Material 3, динамический tonal-палитр от seed-цвета, светлая и тёмная темы).

## Возможности приложения 

- **Изображения** (через Pillow): `png`, `jpg`, `jpeg`, `webp`, `bmp`, `tiff`, `gif`, `ico`, `tga`, `ppm`, `pcx`. Сохраняет анимацию для GIF/WebP, корректно сглаживает альфа-канал при экспорте в JPEG/BMP.
- **Аудио** (через ffmpeg): `mp3`, `wav`, `flac`, `ogg`, `m4a`, `aac`, `wma`, `opus`, `aiff`. Подобраны разумные битрейты по умолчанию.
- **Видео** (через ffmpeg): `mp4`, `mkv`, `avi`, `mov`, `webm`, `flv`, `wmv`, `m4v`, `mpeg`, `mpg`, `ts`. Двух-проходный экспорт в качественный анимированный GIF (palettegen + paletteuse). Видео можно сохранять в любой аудио-формат — звуковая дорожка будет извлечена.
- **Пакетная конвертация**: добавьте сразу много файлов, выберите целевой формат и нажмите одну кнопку. Прогресс отображается по каждому файлу.
- **Material You интерфейс**: seed-цвет генерирует всю палитру, светлая/тёмная темы переключаются одной кнопкой, скруглённые карточки и чипы быстрого выбора популярных форматов.

## Скриншот

> Запустите `python app.py` — увидите.

## Установка

```bash
pip install -r requirements.txt
```

Для аудио и видео нужно установить **ffmpeg** и добавить его в `PATH`:

- Windows: <https://www.gyan.dev/ffmpeg/builds/> или `winget install ffmpeg`
- macOS: `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg`

Проверка: `ffmpeg -version` в терминале.

## Запуск

```bash
python app.py
```

## Как пользоваться

1. Нажмите **«Выбрать файлы»** и добавьте картинки, аудио или видео — программа определит тип каждого файла.
2. Выберите целевой формат — через выпадающий список или один из чипов быстрого доступа.
3. (Необязательно) Укажите папку для сохранения. По умолчанию готовые файлы сохраняются рядом с исходными.
4. Нажмите **«Конвертировать»**. Прогресс по каждому файлу виден в очереди.
