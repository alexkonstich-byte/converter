# Универсальный конвертер

Десктопное приложение на Python для конвертации **изображений, аудио и видео**. Интерфейс сделан на Flet 1.x по Material 3 (Material You): палитра строится из одного seed-цвета, есть светлая, тёмная и системная тема.

## Возможности

- **Изображения** (Pillow): `png`, `jpg`, `webp`, `avif`, `bmp`, `tiff`, `gif`, `ico`, `tga`, `ppm`, `pcx`, `pdf`. Анимированные GIF/WebP сохраняют все кадры и их задержки. Прозрачность при сохранении в JPEG/BMP/PDF заливается белым. Несколько картинок можно собрать в один PDF.
- **Аудио** (ffmpeg): `mp3`, `wav`, `flac`, `ogg`, `m4a`, `aac`, `wma`, `opus`, `aiff`.
- **Видео** (ffmpeg): `mp4`, `mkv`, `avi`, `mov`, `webm`, `flv`, `wmv`, `m4v`, `mpeg`, `mpg`, `ts`, а также качественный GIF (двухпроходная палитра). Из видео можно извлечь звук в любой аудиоформат.
- **Настройки**: качество и размер картинок; битрейт, частота и каналы звука; кодек H.264/H.265/AV1, CRF или фиксированный битрейт, разрешение, кадрирование (9:16, 1:1, 4:5…), fps; аппаратное кодирование NVENC / Quick Sync / AMF / VideoToolbox.
- **Обрезка** аудио и видео по времени (`1:30` — `2:45`).
- **Водяной знак** на картинках и видео, с кириллицей.
- **Выбор звуковой дорожки** у видео с несколькими дорожками — отдельно для каждого файла.
- **Пресеты**: YouTube 1080p/4K, Сторис 9:16, Telegram, почта, FLAC-архив, MP3 320, JPEG/WebP для веба.
- **Очередь**: прогресс и оценка размера для каждого файла, общий ETA, пауза, отмена, журнал ffmpeg, контрольные суммы MD5/SHA-256, компактный режим поверх окон.

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

Для аудио и видео нужен **ffmpeg** в `PATH` (картинки работают и без него):

- Windows: `winget install Gyan.FFmpeg` (приложение может запустить установку само)
- macOS: `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg`

Проверка: `ffmpeg -version`.

На Linux для встроенного видеоплеера нужен `libmpv` (`sudo apt install libmpv2`), а для выбора файлов — `zenity`. Без `libmpv` вместо плеера показывается кадр из видео.

## Запуск

```bash
python app.py
```

## Как пользоваться

1. Нажмите **«Добавить»** и выберите файлы. Тип каждого файла определится автоматически.
2. В блоке **«Во что конвертировать»** выберите группу (картинка / аудио / видео) и формат. Несовместимые форматы недоступны.
3. По желанию выберите пресет или настройте качество. Показываются только настройки, которые повлияют на результат.
4. Нажмите **«Конвертировать»**. Конвертацию можно поставить на паузу или отменить, недописанные файлы удаляются.

## Структура

```
converter/
├── app.py             # окно, очередь, запуск конвертации
├── settings_panel.py  # карточки настроек
├── preview.py         # предпросмотр и плеер
├── ui_kit.py          # тема Material You и общие M3-компоненты
├── converter.py       # движок конвертации (Pillow + ffmpeg)
├── tests/             # тесты движка (pytest)
└── requirements.txt
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тестовые медиафайлы генерируются самим ffmpeg; если его нет, видео- и аудиотесты пропускаются.
