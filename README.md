# Универсальный конвертер

Десктопное приложение на Python для конвертации **изображений, аудио и видео** между десятками форматов. Интерфейс выполнен в стиле **Material You** на базе Flet (Material 3, динамический tonal-палитр от seed-цвета, светлая и тёмная темы).

## Возможности приложения 

- **Графические форматы** (через Pillow): `png`, `jpg`, `jpeg`, `webp`, `bmp`, `tiff`, `gif`, `ico`, `tga`, `ppm`, `pcx`. Поддерживается анимация для GIF и WebP, а при сохранении в JPEG или BMP альфа-канал корректно сглаживается.
- **Аудио** (через ffmpeg): `mp3`, `wav`, `flac`, `ogg`, `m4a`, `aac`, `wma`, `opus`, `aiff`. Для каждого формата заданы оптимальные битрейты по умолчанию.
- **Видео** (через ffmpeg): `mp4`, `mkv`, `avi`, `mov`, `webm`, `flv`, `wmv`, `m4v`, `mpeg`, `mpg`, `ts`. Реализован двухпроходный экспорт в качественный анимированный GIF (через палитры palettegen + paletteuse). Видеофайл можно конвертировать в любой аудиоформат — звуковая дорожка будет извлечена автоматически.
- **Пакетная обработка**: загружайте несколько файлов одновременно, выбирайте единый целевой формат и запускайте конвертацию одной кнопкой. Ход выполнения отслеживается для каждого файла индивидуально.
- **Интерфейс в стиле Material You**: основной цвет задаёт всю цветовую схему, переключение между светлой и тёмной темой — в один клик, элементы управления выполнены в виде карточек со скруглёнными углами и чипов для быстрого выбора популярных форматов.

## работа приложения 

python app.py

## Установка

```bash
pip install -r requirements.txt
```

Для аудио и видео нужно установить **ffmpeg** и добавить его в `PATH`:

- нужен ffmpeg
  ffmpeg -version

## Запуск

```bash
python app.py
```

## Как пользоваться

1. Нажмите **«Выбрать файлы»** и добавьте картинки, аудио или видео — программа определит тип каждого файла.
2. Выберите целевой формат — через выпадающий список или один из чипов быстрого доступа.
3. (Необязательно) Укажите папку для сохранения. По умолчанию готовые файлы сохраняются рядом с исходными.
4. Нажмите **«Конвертировать»**. Прогресс по каждому файлу виден в очереди.
